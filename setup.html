Yahoo login (one time)

Nothing you type here is saved or sent anywhere. This page only builds a link.

1. Paste your Yahoo Client ID

From your app on developer.yahoo.com (the long text that starts with dj0y).

Open Yahoo and click Agree

If Yahoo shows an error about “scope” instead of the Agree page, use this link instead: plain Yahoo link.

2. Copy the address of the page that fails to load

After you click Agree, the browser goes to an address starting with https://localhost:8080 and shows “can’t be reached”. That is expected. Copy the whole address from the address bar and paste it here.

3. Give the code to GitHub within a few minutes

Open the Yahoo login workflow, click “Run workflow”, paste the code, and click the green “Run workflow” button.
